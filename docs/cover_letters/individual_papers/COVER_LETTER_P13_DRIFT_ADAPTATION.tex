SUBJECT: Submission of Manuscript P13 — Intra-Campus Federated Averaging under Local Gradient Isolation

Dear Editor-in-Chief and Associate Editors,

We are pleased to submit our original research manuscript titled "Intra-Campus Federated Averaging under Local Gradient Isolation" for publication consideration in Adaptive Behavior.

1. SUBSYSTEM BACKGROUND AND MOTIVATION
Collaborative model updates across multiple campus departments are essential for improving face recognition and behavior models over time. However, centralizing training features violates student privacy and creates honeypot targets. This paper presents an intra-campus Federated Learning (FL) framework based on Federated Averaging (FedAvg).

2. CORE TECHNICAL CONTRIBUTIONS AND NOVELTY
  - Local Gradient Isolation: Computes deep feature model updates locally on departmental edge clients, sharing only encrypted parameter gradients with the central coordinator.
  - Global Model Convergence: Demonstrates that intra-campus FedAvg achieves 97.8% global model classification accuracy across 50 training rounds, performing within 0.2% of a centralized training baseline.
  - Privacy-Preserving Adaptation: Ensures raw student images and feature vectors never leave local edge devices, enforcing the "Right to be Forgotten" via local gradient purging.

3. SUITABILITY FOR ADAPTIVE BEHAVIOR
This paper fits Adaptive Behavior's scope in adaptive learning algorithms, decentralized model evolution, cooperative multi-agent adaptation, and local learning constraints.

4. ETHICS AND ORIGINALITY DECLARATIONS
This work represents original research, is not submitted elsewhere, and complies strictly with decentralized data protection rules.
