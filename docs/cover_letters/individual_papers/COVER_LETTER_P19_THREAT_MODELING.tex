SUBJECT: Submission of Manuscript P19 — Threat Modeling and Trusted Computing Base Confinement on Resource-Constrained Edge Hardware

Dear Editor-in-Chief and Associate Editors,

We are pleased to submit our original research manuscript titled "Threat Modeling and Trusted Computing Base Confinement on Resource-Constrained Edge Hardware" for publication consideration in the Journal of Computer Security (IOS Press).

1. SUBSYSTEM BACKGROUND AND MOTIVATION
Deploying privacy-preserving vision and acoustic pipelines on edge hardware (such as the NVIDIA Jetson Orin Nano) requires minimizing the Trusted Computing Base (TCB) while operating within strict physical RAM limits (<= 2.0GB). Unconfined edge platforms risk memory exhaustion and side-channel leakage. This paper presents a formal threat model and TCB memory confinement architecture.

2. CORE TECHNICAL CONTRIBUTIONS AND NOVELTY
  - Comprehensive Edge Threat Model: Analyzes physical access attacks, memory dump attacks, unauthorized IPC access, and model inversion vectors in edge deployments.
  - TCB RAM Footprint Confinement: Implements lightweight memory isolation (`EdgeOptimizer`), restricting system RAM utilization to <= 2.0GB and VRAM to <= 4.5GB while sustaining 30 FPS processing.
  - Verification of Memory Sanitization: Proves that memory-bounded execution prevents out-of-memory crashes and enforces zero residual data retention across process lifecycles.

3. SUITABILITY FOR JOURNAL OF COMPUTER SECURITY
This manuscript fits the Journal of Computer Security's scope in hardware-software security modeling, TCB minimization, embedded systems security, and memory boundary isolation.

4. ETHICS AND ORIGINALITY DECLARATIONS
This manuscript is original, has not been published previously, and is not currently under review elsewhere.
