SUBJECT: Submission of Manuscript P8 — Cryptographic Non-Repudiation Audit Ledger via Merkle Hash Chains

Dear Editor-in-Chief and Associate Editors,

We are pleased to submit our original research manuscript titled "Cryptographic Non-Repudiation Audit Ledger via Merkle Hash Chains" for publication consideration in IEEE Transactions on Dependable and Secure Computing (TDSC).

1. SUBSYSTEM BACKGROUND AND MOTIVATION
In institutional attendance and surveillance systems, administrative database logs are vulnerable to unauthorized modification, deletion, or backdating by malicious administrators. Ensuring non-repudiation and tamper-evident auditability without storing sensitive biometric records requires an immutable cryptographic ledger. This paper presents a light-weight cryptographic trust layer for operational event logging.

2. CORE TECHNICAL CONTRIBUTIONS AND NOVELTY
  - Append-Only Merkle Tree Ledger: Constructs a SHA-256-chained binary Merkle tree ledger that serializes attendance events and compliance alerts into immutable root hashes.
  - Linear Integrity Verification: Formulates an O(M) verification algorithm that validates ledger chain linkages and detects historical record tampering or block content modifications.
  - Zero-Overhead Persistence: Achieves atomic write performance and zero-latency transaction verification without the computational overhead of heavy distributed consensus blockchains.

3. SUITABILITY FOR IEEE TDSC
This manuscript fits TDSC's scope in cryptographic trust architectures, secure data logging, non-repudiation protocols, and dependable system design.

4. ETHICS AND ORIGINALITY DECLARATIONS
This work represents original research, is not under consideration elsewhere, and adheres strictly to cryptographic security principles.
