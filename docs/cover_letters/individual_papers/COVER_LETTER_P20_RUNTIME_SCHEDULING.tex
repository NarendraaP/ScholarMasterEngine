SUBJECT: Submission of Manuscript P20 — Runtime Scheduling and Dynamic Threshold Calibration in Scaled Open-Set Galleries

Dear Editor-in-Chief and Associate Editors,

We are pleased to submit our original research manuscript titled "Runtime Scheduling and Dynamic Threshold Calibration in Scaled Open-Set Galleries" for publication consideration in IEEE Transactions on Parallel and Distributed Systems (TPDS).

1. SUBSYSTEM BACKGROUND AND MOTIVATION
In large-scale biometric vector spaces, as gallery sizes grow from 1,000 to 100,000 enrolled identities, fixed distance thresholds lead to an exponential increase in false-positive matches. Maintaining sub-2ms query search latencies alongside strict open-set identification accuracy requires adaptive scheduling and dynamic threshold calibration. This paper presents a dynamic threshold scaling framework for high-throughput vector search.

2. CORE TECHNICAL CONTRIBUTIONS AND NOVELTY
  - Logarithmic Threshold Calibration Equation: Formulates an adaptive distance threshold equation tau(N) = tau_base + alpha * log(N) that automatically tightens search bounds as gallery size N expands.
  - Parallel Index Scheduling: Optimizes GPU-accelerated FAISS Inverted File (IVF-PQ) index scheduling across multi-core architectures, sustaining sub-2ms query latencies at 100,000-vector scale.
  - Mathematical & Empirical Bounds: Proves that logarithmic threshold scaling suppresses false-positive accumulation while maintaining a 99.2% Open-Set Identification Rate (OSIR).

3. SUITABILITY FOR IEEE TPDS
This paper directly fits IEEE TPDS's focus on high-performance parallel algorithms, high-throughput vector index scheduling, scalability modeling, and distributed search systems.

4. ETHICS AND ORIGINALITY DECLARATIONS
