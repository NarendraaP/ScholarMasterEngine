SUBJECT: Submission of Manuscript P15 — Glassmorphic Situational Awareness Interfaces and Engagement Estimation in Smart Classrooms

Dear Program Committee Chairs and Reviewers,

We are pleased to submit our original research manuscript titled "Glassmorphic Situational Awareness Interfaces and Engagement Estimation in Smart Classrooms" for consideration at ACM CHI.

1. SUBSYSTEM BACKGROUND AND MOTIVATION
Administrative dashboards for campus security and faculty oversight often overload users with raw video feeds, complex metrics, and un-triaged alerts, increasing cognitive fatigue and response delays. Furthermore, displaying raw facial streams violates student privacy. This paper presents a human-centered, glassmorphic UI dashboard paired with privacy-preserving engagement estimation.

2. CORE TECHNICAL CONTRIBUTIONS AND NOVELTY
  - Symbolic Skeleton & Mesh UI: Renders anonymized keypoint overlays and 468-landmark facial mesh geometry without displaying raw camera pixels, ensuring high visual clarity while preserving identity privacy.
  - Multi-Metric Engagement Score (E): Computes a weighted composite engagement score (E = 0.7 * E_head + 0.3 * E_eye) combining PnP head pose rotation and Eye Aspect Ratio (EAR) blink analysis.
  - Cognitive Load Reduction: Conducts user interface evaluations demonstrating reduced administrative triage time and lower operator cognitive fatigue compared to traditional multi-monitor CCTV panels.

3. SUITABILITY FOR ACM CHI
This work fits ACM CHI's focus on human-computer interaction, situational awareness interfaces, cognitive load optimization, and ethical visual design in smart environments.

4. ETHICS AND ORIGINALITY DECLARATIONS
This work represents original research, is not published elsewhere, and adheres strictly to human-centered interface design ethics.
