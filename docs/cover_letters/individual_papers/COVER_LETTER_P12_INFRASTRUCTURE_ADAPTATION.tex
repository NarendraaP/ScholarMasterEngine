SUBJECT: Submission of Manuscript P12 — Infrastructure Optimization and Scoped RBAC in Multi-Tenant Platforms

Dear Editor-in-Chief and Associate Editors,

We are pleased to submit our original research manuscript titled "Infrastructure Optimization and Scoped RBAC in Multi-Tenant Platforms" for publication consideration in IEEE Transactions on Network and Service Management (TNSM).

1. SUBSYSTEM BACKGROUND AND MOTIVATION
Multi-tenant institutional sensing platforms require multi-tier role-based access control (RBAC) to enforce department-level data isolation while minimizing storage write IOPS on edge flash media. Monolithic administrative accounts create severe vulnerability surfaces. This paper presents an optimized RBAC middleware and flash wear-leveling infrastructure.

2. CORE TECHNICAL CONTRIBUTIONS AND NOVELTY
  - 7-Role Hierarchical RBAC Matrix: Implements an RBAC1-compliant authorization hierarchy in FastAPI middleware, restricting data access across Super Admin, HOD, Faculty, Student, and Security roles.
  - Departmental Query Isolation: Enforces query-level isolation ensuring HODs access only their department's data, preventing cross-tenant data exposure.
  - Flash Storage IOPS Minimization: Reduces storage write amplification to 0.02 MB/s through RAM caching and atomic file swaps, extending edge flash memory lifespan by 4x.

3. SUITABILITY FOR IEEE TNSM
This manuscript aligns with TNSM's focus on multi-tenant network management, access control frameworks, infrastructure optimization, and service governance.

4. ETHICS AND ORIGINALITY DECLARATIONS
